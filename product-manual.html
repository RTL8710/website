这是一套设备端 AI 视觉一体化产品:从多平台固件(瑞芯微 / 海思 / 英伟达等)、设备端边缘 AI(YOLO 检测 + 视觉大模型),到 AWS 云、Flutter App 与本 Web 控制台,云边端全链路打通。 它最大的不同在于:AI 在设备本地算力上运行——拔了网线也能检测、也能对画面做自然语言问答;同时具备工业级录像可靠性(多模式录像、连续运行不丢录像)与整套可白标的交付能力。

核心亮点 · Core Highlights

📡

WebRTC 实时视频Low-latency Live

基于 WebRTC 的远程实时查看:P2P 低延迟、自带内网穿透,无需端口映射即可随时随地看;RTC / RTSP 多传输自动回退。

🧠

设备端视觉大模型On-device VLM

对实时画面开放式问答,看懂场景、读出画面文字(OCR),本地 + OpenAI 双模式,断网可用。

🎯

设备端 AI 检测Edge AI · YOLO

YOLO 多类目标检测,检测框直接画在画面(OSD),支持 Foxglove / ROS 推送,全程本地算力。

📹

多摄像头同屏Multi-stream

单设备多路:实时多路同屏直播,本地回放多路同步复盘,共用一条时间轴。

🛡️

录像可靠不丢Never-lose

循环 / 缩时 / 预录 / 手动 + 事件录像;本地+云端;看门狗自愈、断电保护,连续运行不丢录像。

🧩

一套固件多平台One Firmware

君正 / 海思 / 瑞芯微 / 全志 / 联咏 / 英伟达六大平台一套固件,换芯片不重写。

🌐

云边端 + 全球白标White-label

设备 + App + Web 门户整套可白标(品牌/主题色/多语言),全球三区域,OTA 在线升级。

MONITOR · 监控
01

Home实时监控总览

登录后的实时监控主页,直接查看设备实时画面。

  • 多路摄像头实时直播(WebRTC,随时随地)
  • 左右快捷工具:截图 / 录制 / 对讲 / AI 画面布局 / 全屏 / 云端
  • 底部 Play / Mute 控制播放与声音
02

Video Playback本地录像回放

检索并回放设备本地录像,带 24 小时可视化时间轴。

  • 时间轴 00:00–24:00,分 CAM1 / CAM2 两路,Loop / EMR / Timelapse 三色区分
  • 录像列表:每段含时间 / 分辨率 1920×1080 / 编码 H.264 / 时长 / 大小 / 文件号
  • 单段可 截图(Jpeg) / 下载(Video) / 删除(Del);支持按类型筛选与翻页
  • 累计文件号已达 14.7 万+,印证长期录制不丢
03

Cloud Playback云端录像回放

回放已上云的录像,设备损坏/丢失也不影响取证。

  • 按时间区间检索云端录像
  • 云端存事件录像(EMR)· 1080P,可分通道
  • 与本地录像互为备份
04

Image Playback抓拍图片回放

检索并查看设备抓拍的 JPEG 图片。

  • 按时间检索抓拍图
  • 支持事件/定时抓拍图片浏览
05

Chat Device视觉大模型对话

核心亮点。对设备实时画面进行开放式自然语言问答。

  • 发一帧画面提问,设备端视觉大模型看懂场景并回答
  • 可描述场景类型、读出画面里的文字(OCR)、推断环境
  • 本地 VLM + OpenAI 双模式,断网也可用
  • 不是"数人头",是真正"看懂画面"
