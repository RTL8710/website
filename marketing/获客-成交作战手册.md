# 成交作战手册(冯总 · 吴总)· 见面揣着用

> 价值排序(你的实战判断):**架构 = 护城河 > 音视频底座 = 刚需/定价基准 > AI = 钩子/彩蛋**

## 一、价值三层楼(给老板一听就懂)
| 层 | 是什么 | 销售角色 |
|---|---|---|
| 🏛️ 地基 | **嵌入式架构:稳定·高效·易扩展** | 护城河 + 议价权,最难复制 |
| 🔧 主体 | **实时音视频对讲 + 录像(本地/云)· 断电不丢** | 刚需,客户离不开,**按这个定价** |
| ✨ 装修 | **AI(检测/对话/读字)** | 钩子,抓眼球,加购模块 |
> "底层架构稳、易扩展,中间实时音视频+录像是刚需,顶上还能加 AI。**地基我帮你打牢,你想盖几栋楼(几条产品线)都行。**"

## 二、演示顺序(翻过来:先值钱的,AI 收尾)
1. **架构稳/易扩展**:连续跑不重启、换芯片不重写、加型号快
2. 🔥 **实时直播 + 双向对讲**:随时随地看得见、喊得上(~300ms)
3. 🔥 **本地录像**:循环/缩时/预录/事件 + **断电不丢录像**
4. 🔥 **云录像**:边录边传,**设备丢了云端还在**
5. ✨ **AI 彩蛋**:实时画框认人车 + 拿画面问它读字
6. 💥 **断网演示**:当面拔网线,音视频/录像/AI 照跑(最炸,必做)
7. **整套白标**:设备/App/云贴他品牌

## 三、冯总(记录仪 · 旧客 5000/月锚)
- **主打**:架构稳→不崩不丢 + 实时对讲 + 断电不丢录像 + 云端留存;AI 当差异化彩蛋
- **翻锚**:让他看到这是整套成品/方案,不是去年按月外包
- **节奏**:本周视频桥接保温 → 下周实物演示(演示机移植约一周)
- **拿承诺**:"帮我在 XX 型号试一下"

## 四、吴总(摄像头 · 工厂品牌一体 · 想扩产品线)
- **主打**:🏛️ 架构易扩展 → 多产品线——正面回答他"做不了太多产品线/平台/协议/产测怎么结合"
  > "你卡的就是没有稳、易扩展的底座。我这套一次搭好,你换芯片、出新型号,底座复用、快速出货——这才是你能扩产品线的底气。"
- **软件他不懂**:强打"软件这块我帮你扛、帮你理,你只管硬件和产品方向"
- **节奏**:他刚凉("哦"),**慢火**——卸压"公司/股权的事不急,先看演示、做小试点";股权别在微信谈,拉到桌上
- **警惕**:主管研发必须是**联合创始人有真股份**,不是挂头衔打工;确认他能拍板+有预算

## 五、合作模式(按底座定价,AI 加购)
1. **按片授权(首选,量大)**:开发费 + 每台授权费(参考 8–30 元/台可调)
2. **项目制**:固定项目费(首付 30–50% + 节点付款)
3. **平台/模块授权**:底座授权 + 年费/顾问费(适合吴总平台级)
4. **代码买断**:一次性,报价往高

## 六、异议应对(背熟)
- **太贵/海康才多少** → "海康是拼价标品;我给的是别人做不出的稳底座+差异化,你卖的是溢价和你的品牌"
- **先免费做 demo** → "可小成本做一个型号试点(收试点费),绝不免费做核心"
- **你来上班多省事(吴总)** → "合作你不用养编制、按量付费风险更小,我专做这个更快"
- **你一个人靠谱吗** → "从架构、固件、音视频到云、AI 一个人闭环,对接最省心;17 年安防,多领域落地过"
- **把代码给我们自己做** → "核心做成加密模块/授权激活,能用不外流;要自主可谈买断(往高)"
