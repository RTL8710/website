## 二、6 段配音脚本(逐段对齐动效,可直接录音)

### 第 1 段 · 钩子(promo-anim-demo.html · Scene A)
- **中**:「这台设备,我拔了网线。它,还在认人。AI 全在设备里算,不上云、不卡顿、不泄露。」
- **EN**: "I just unplugged it from the internet. It still recognizes everyone. All AI runs on the device — no cloud, no lag, no data leaving the box."

### 第 2 段 · 六路同时(demo.html · Scene B)
- **中**:「六路摄像头同时跑,YOLO 80 类目标检测,每秒 150 帧以上——全部在一颗芯片上本地完成。这不是云端 API,这是端侧算力。」
- **EN**: "Six streams at once. YOLO, 80 object classes, 150+ FPS — all on a single on-device chip. Not a cloud API. Real edge compute."

### 第 3 段 · 设备端视觉大模型对话(promo-anim-full.html · Scene S3)
> 已对齐 Web 门户「Chat Device」真实行为:这是 **VLM 视觉大模型**,看着摄像头画面做**开放式场景问答**,不只是识别物体——能描述整个场景、读出画面里的文字。
- **中**:「设备里跑着视觉大模型。你拿实时画面直接问它『画面里有桌子吗?这是什么地方?』——它看懂场景、读出画面里的招牌文字、推断出这是商场还是车间。不是查数据库,是真的『看懂了』。」
- **EN**: "A vision LLM runs inside the device. Show it a live frame and just ask — 'is there a table? what is this place?' It describes the whole scene, even reads the text on the signs. It doesn't look up a database. It actually understands what it sees."
- 区分:**数物体/识别人/跌倒** = AI 检测(YOLO,第 2 段);**看懂场景/问答/读字** = Chat Device VLM(本段)。别混。
- ⚠️ 此段底层**必须**换成你真实的 Chat Device 问答录屏(就用你那条「有没有桌子在画面里面?」→ 模型描述商场场景+读出域名 的真实对话,极有说服力)。

### 第 4 段 · 一年不重启(full.html · Scene S4)
- **中**:「连续运行一年,零重启,不丢一帧录像。看门狗自愈、索引自修复、断电保护——工业现场要的是这个。」
- **EN**: "365 days running. Zero reboots. Not a single frame lost. Watchdog self-heal, index auto-repair, power-loss protection — what the field actually demands."

### 第 5 段 · 多芯片一套固件(full.html · Scene S5)
- **中**:「君正、海思、瑞芯微、全志、联咏、英伟达——六大平台,一套固件。换芯片不重写,出货不卡脖子。」
- **EN**: "Ingenic, HiSilicon, Rockchip, Allwinner, Novatek, NVIDIA — six platforms, one firmware. Switch SoC without a rewrite."

### 第 6 段 · 全栈白标 + 收口(full.html · Scene S6)
- **中**:「设备、App、云门户——整套可白标成你的品牌。你有市场和渠道,我把别人做不出的 AI 全栈做进去。按台授权,一起赚。」
- **EN**: "Device, app, cloud portal — white-labeled to your brand. You bring the market. I bring the on-device AI stack others can't build. License per unit, and we grow together."

## 二·补 实机验证后新增的卖点(2026-06-20 截屏真机后补)

> 看了真机(App 实时视频页 + Web 门户 Chat Device)后,以下是我之前文案漏掉、但你**真有**的差异化,务必加进物料:

| 卖点 | 真实证据 | 怎么用 |
|------|----------|--------|
| **VLM 场景理解 + 读字(OCR)** | Chat Device 里问「有没有桌子」,模型自己描述出「玻璃幕墙商场/展厅、灰地面、吊灯」并**读出画面里的域名文字**推断出公司 | 比「数人头」高级一个维度,主打「设备自己看懂现场、能读招牌/铭牌/车牌文字」 |
| **Foxglove 推送** | AI 检测页有「Foxglove 推送」开关 | 对**机器人/ROS** 客户是强信号:检测结果可直接进机器人可视化栈 |
| **多摄像头同屏直播** | 实时视频页**两路同屏并发**(主画面 + 第二路同时播,选择器 1/2 同时点亮),当前演示 2 路 | 印证「多路同时」不是 PPT、不是切换:单设备多路**同时直播**是真的 |
| **整套 Web 门户白标** | 门户主题「深靖蓝·青」可换、可切 EN、admin 登录 | 主打「连云端控制台都是你的品牌、你的色、你的语言」 |
| **OpenAI 服务 + 本地并存** | 门户左栏有「OpenAI Service」+ 本地 VLM | 灵活:断网走本地 VLM,联网可挂 OpenAI,客户按成本/合规自选 |
| **云回放真有数据** | App 云回放页:最近录像 09:24:55、`EMR 事件录像`、`1920×1080`、分通道 `CH0`、可按**日期+设备**筛选 | 「云端录像不怕丢」坐实:云端存的是 1080P 事件录像、可检索 |
| **本地录像极密** | App 本地回放页:单日 **2307 段**、三模式分色 `Loop/EMR/Timelapse`、多路 `CAM1/CAM2`、`1920×1080` | 「连续录不丢」坐实:一天 2300+ 段、循环/缩时/事件三模式齐全 |
| **多摄像头同步回放** | 本地回放可**双路同屏**回放(CAM2 主画面 + 第二路同时播,共用一条时间轴) | 主打「多路同步复盘」,工业/机器人现场要的就是这个 |
| **录像模式全 + 14.7万文件** | 录像设置页:循环/手动/**缩时**/**预录**模式,录像类型可选**本地/云端/本地+云端**;**累计录像文件数 147006** | 「连续录不丢」最硬证据:**14.7 万个文件累计无损**;第 4 段「1年不重启」可改用这个真实数字 |
| **OTA 在线升级** | 升级页:设备版本 0.1.50 → 云端 1.0.0、「有新版本」提示、Check/升级、升级信息 | 主打「出货后远程统一升级,不用召回」,对量产客户是运维刚需 |
| **全球多区域** | 区域设置页:**东南亚(东京)/ 美洲 / 欧洲(巴黎)** 三区域可选 | 海外客户(数码那条路)强信号:就近接入、低延迟、数据合规;主打「全球可部署」 |
