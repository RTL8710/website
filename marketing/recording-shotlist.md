# 录屏清单(成片真素材)· 照做即可

> 配 `promo-script-copy.md` 用。动画(promo-anim-*.html)是包装壳,这份清单里的**真录屏**才是说服力来源。
> 通用要求:**横屏录、1080P 以上、每段前后留 2 秒静止**(方便剪辑);手机用系统录屏,Web 用 QuickTime/OBS 录 Chrome 窗口;**遮挡隐私**(真实人脸、真实域名/招牌看情况打码,但「读字」那段要留一个能展示 OCR 的非敏感文字)。
> 优先级:⭐⭐⭐ 必录(没有就没视频)→ ⭐ 锦上添花。

---

## 王牌段 · Chat Device 视觉大模型问答 ⭐⭐⭐
- **在哪**:Web 门户 `https://192.168.2.102:100` → 左栏 **Chat Device**
- **怎么操作**:用你已有的那条真实对话——发一帧实时画面,问「**有没有桌子在画面里面?**」→ 等模型回答(它会描述商场/展厅场景、**读出画面里的文字**并推断公司)。
- **录什么**:从你打字提问 → 画面缩略图出现 → 模型逐字吐出回答的**完整过程**(打字机效果最好看)。
- **时长**:15–25 秒。
- **要点**:这是全片最强证据,**让回答完整可读**;如果能再补一条「这是什么地方?」追问,展示连续对话更佳。对应配音第 3 段。

## 必录段 · 实时视频双路同屏直播 ⭐⭐⭐
- **在哪**:App → 设备 `smartCameraHome` → **实时视频**
- **怎么操作**:停在**两路同屏**画面(主画面 + 右上第二路,底部选择器 1/2 都亮),轻微移动镜头前的物体让画面有动态。
- **录什么**:双路同时直播的实时画面,最好镜头前有人/物在动。
- **时长**:8–12 秒。
- **要点**:证明「多路同时直播、不是切换」。对应配音第 2 段。

## 必录段 · 拔网仍跑(断网本地 AI)⭐⭐⭐
- **在哪**:App 实时视频页 / 或设备本体
- **怎么操作**:画面里先正常跑 → **物理拔掉设备网线**(或断 WiFi)→ 展示设备**仍在出画面 / AI 仍在工作**。
- **录什么**:拔线动作(给个网口特写)+ 拔线后画面照常 + 若能展示 AI 检测框/本地问答仍可用更佳。
- **时长**:10–15 秒(拔线前 3s + 拔线 + 拔线后 8s)。
- **要点**:全片钩子(配音第 1 段「拔了网线,它还在认人」)。**这段必须真拔,效果最炸,也最不能造假。**

## 必录段 · 双路同步回放 ⭐⭐⭐
- **在哪**:App → 设备 → 底部 **本地回放** → 切到**双摄像头**
- **怎么操作**:进入后展示当天密集时间轴(**2307 段** 那个计数给个特写)→ 点一段录像 → **两路同屏同步回放**。
- **录什么**:时间轴密度 + 三模式分色(Loop/EMR/Timelapse 图例)+ 双路同步播放。
- **时长**:12–18 秒。
- **要点**:证明「多路同步复盘 + 录像极密不丢」。对应配音第 4 段。

## 锦上添花段(有空再录)

### AI 检测 OSD 检测框 ⭐
- **在哪**:App AI检测页确认「绘制检测框 OSD」开 → 回实时视频,**让镜头前有人/有目标**
- **录什么**:实时画面上**自动画出 YOLO 检测框 + 标签**的瞬间。
- **时长**:6–10 秒。
- **要点**:配音第 2 段的硬证据;没有目标时不画框,所以**镜头前要有人走动**。

### 录像可靠性数字 ⭐
- **在哪**:App → 设备设置 → **录像设置**
- **录什么**:**录像文件数 147006** 给个特写 + 四种模式(循环/手动/缩时/预录)+ 录像类型(本地/云端/本地云端)。
- **时长**:5–8 秒。
- **要点**:配音第 4 段可把动画里的「365」换成真实「14.7 万文件」。

### 全栈白标 + 全球区域 ⭐
- **在哪**:Web 门户(主题「深靖蓝·青」可换色/切 EN)+ App 区域设置(东京/美洲/巴黎三区)
- **录什么**:门户换一次主题色或切英文 + 区域三选列表。
- **时长**:各 5 秒。
- **要点**:配音第 5、6 段(一套固件 / 白标 / 全球可部署)。

### OTA 在线升级 ⭐
- **在哪**:App → 设备设置 → 升级
- **录什么**:设备版本 0.1.50 →「有新版本」→ 点升级。
- **时长**:5–8 秒。
- **要点**:量产客户运维刚需的佐证。
